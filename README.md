# Advanced-3D - Ultimate Sphere Power

Webブラウザ上で動作する、Three.jsベースの簡易3D粘土彫刻ツールです。
マウスドラッグで球体の頂点を直接操作し、直感的に形状を変化させることができます。
<img width="1916" height="1037" alt="スクリーンショット 2026-06-04 160704" src="https://github.com/user-attachments/assets/b64956f8-1d57-40aa-b4e6-1801daa548f1" />

## 🛠 機能
* **盛る (Add)**: ブラウザ上の球体に粘土を盛り上げます。
* **削る (Subtract)**: 球体から粘土を削り取ります。
* **ブラシサイズ調整**: 影響範囲の大きさを変更可能。
* **強度調整**: 彫刻の深さ・高さを変更可能。

## 🚀 使い方
1. このリポジトリをクローンまたはダウンロードします。
2. `index.html` をブラウザで開きます。
3. 画面上のボタンで「盛る」か「削る」を選択します。
4. マウスで球体をドラッグすると、その箇所が変形します。

実装のポイント解説
このコードの仕組みを理解するために、以下の技術的な要素が重要です。

Raycaster: 画面上の2D座標（マウス位置）から、3D空間上のどの頂点に触れているかを判定するために使用されています。

BufferGeometry: 球体の頂点情報を直接操作することで、リアルタイムな変形を実現しています。

Vertex Normal Update: geometry.computeVertexNormals() を呼ぶことで、変形後の表面の影（陰影）を再計算し、リアルな立体感を維持しています。
